# LeetCode

My solutions to LeetCode problems, written in C++, as part of daily DSA practice.

## Structure

Each problem lives in its own folder, named with the problem number and title:

```
leetcode/
├── 0001-two-sum/
│   ├── solution.cpp
│   └── README.md
├── 0005-longest-palindromic-substring/
│   ├── solution.cpp
│   └── README.md
└── ...
```

Each problem's `README.md` includes:
- A link to the problem
- Difficulty
- My approach
- Time/space complexity
- Result (runtime/memory, if solved on LeetCode)
